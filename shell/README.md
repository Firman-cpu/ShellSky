# ShellSky shell

This directory contains the Quickshell runtime and UI components.

ShellSky targets the stable Quickshell release shipped by Arch Linux. The runtime should be started with the shell root file and tested under a Wayland session with Hyprland.

## Development

Run from the shell directory or installed configuration:

```bash
qs -p shellsky.qml
```

Use the system check before starting:

```bash
bash scripts/check.sh
```
